# 分诊标签

这些技能以五个规范分诊角色来表述。本文件把这些角色映射到此仓库议题跟踪器里实际使用的标签字符串。

| mattpocock/skills 中的标签 | 我们跟踪器中的标签 | 含义                            |
| -------------------------- | ------------------ | ------------------------------- |
| `needs-triage`             | `needs-triage`     | 维护者需要评估此议题            |
| `needs-info`               | `needs-info`       | 等待报告者提供更多信息          |
| `ready-for-agent`          | `ready-for-agent`  | 已完整规格化，可供 AFK 代理处理 |
| `ready-for-human`          | `ready-for-human`  | 需要人工实现                    |
| `wontfix`                  | `wontfix`          | 不会处理                        |

当某个技能提到一个角色时（例如 "应用 AFK 就绪的分诊标签"），使用本表中对应的标签字符串。

编辑右侧一列，使其与你实际使用的任何词汇相匹配。
