name: research
description: 对照高可信度的一手资料（primary sources）调查一个问题，并把发现留存为仓库里的一个 Markdown 文件。当用户想要研究某个主题、收集文档或 API 事实，或把阅读跑腿的活儿委托给一个后台代理时使用。
---

启动一个**后台代理（background agent）**来做研究，这样它阅读时你能继续干活。

它的职责：

1. 对照**一手资料**（官方文档、源代码、规格、第一方 API）调查问题，而不是它们二手的转述。把每一条主张都追溯到拥有它的源头。
2. 把发现写入单个 Markdown 文件，为每条主张标注来源。
3. 把它保存到仓库已经在存放这类笔记的地方；匹配既有约定，如果没有约定，就放在某个合理的位置并说明放在了哪里。
