设计思考
在编码之前，理解背景并确定一个大胆的美学方向：

目的：这个界面解决什么问题？谁使用它？
基调：选择一个极端：极简到冷酷、极繁到混乱、复古未来主义、有机/自然、奢华/精致、俏皮/玩具感、编辑/杂志风、粗野主义/原始、装饰艺术/几何、柔和/粉彩、工业/实用主义等。有太多风格可供选择。把这些当作灵感，但设计出真正忠于该美学方向的方案。
约束：技术要求（框架、性能、可访问性）。
差异化：是什么让这个界面令人难忘？人们会记住的那一件事是什么？
关键：选择一个清晰的概念方向，并精准执行。大胆的极繁主义和精致的极简主义都可行——关键是有意图，而不是强度。

然后实现可运行的代码（HTML/CSS/JS、React、Vue 等），它应当：

达到生产级并具备功能
视觉上醒目且令人难忘
与清晰的美学观点保持一致
在每个细节上都经过精心打磨
前端美学指南
重点关注：

排版：选择美丽、独特且有趣的字体。避免 Arial 和 Inter 这类通用字体；转而选择能提升前端美学的独特选项；出人意料、富有性格的字体选择。将独特的展示字体与精致的正文字体搭配。
颜色与主题：确定一套连贯的美学。使用 CSS 变量保持一致。主导色配合鲜明点缀，胜过胆怯且平均分布的调色板。
动效：用动画实现效果和微交互。对于 HTML，优先使用纯 CSS 方案。在可用时，React 使用 Motion 库。聚焦高影响力时刻：一次精心编排的页面加载，配合错落有致的揭示（animation-delay），比零散的微交互带来更多愉悦。使用能带来惊喜的滚动触发和悬停状态。
空间构图：出人意料的布局。不对称。重叠。对角线流动。打破网格的元素。充裕的留白或受控的密集。
背景与视觉细节：创造氛围和深度，而不是默认使用纯色。添加与整体美学相匹配的语境效果和纹理。运用渐变网格、噪点纹理、几何图案、层叠透明、戏剧性阴影、装饰性边框、自定义光标和颗粒叠加等创意形式。
绝不使用泛泛的 AI 生成美学，比如滥用的字体族（Inter、Roboto、Arial、系统字体）、陈词滥调的配色方案（尤其是白底紫色渐变）、可预测的布局和组件模式，以及缺乏语境特征的千篇一律设计。

创造性地诠释，做出真正为语境而设计、令人意想不到的选择。没有设计应该完全相同。在浅色和深色主题、不同字体、不同美学之间变化。绝不要在不同生成中趋同于常见选择（例如 Space Grotesk）。

重要：让实现复杂度与美学愿景相匹配。极繁主义设计需要精心编写的代码，包含大量动画和效果。极简或精致设计则需要克制、精准，以及对间距、排版和微妙细节的细致关注。优雅来自对愿景的良好执行。

记住：你能够完成非凡的创意工作。不要保留，展示当你跳出框架思考并全力投入独特愿景时，真正能创造出什么。
