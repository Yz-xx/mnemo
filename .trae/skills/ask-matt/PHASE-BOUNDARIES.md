# 阶段边界

**阶段（phase）** 是会话内部的一块工作：盘问、实现、QA。这个定义是故意模糊的：当你觉得*"好，这块做完了"*时，一个阶段就结束了。

**阶段边界（phase boundary）** 是两个阶段之间的间隙，也是这个决策唯一该待的地方。阶段中途没有决策可做：要么继续，要么把剩下的工作拆给 subagent。在阶段中途压缩会让 agent 丢掉线索。

## 五个选项

| 选项                 | 它的作用                                                       |
| -------------------- | -------------------------------------------------------------- |
| **继续（Continue）** | 留在会话里。完全不切换上下文。                                 |
| **`/clear`**         | 清空上下文窗口，从零开始。                                     |
| **`/handoff`**       | 写出一个可携带的 markdown 文件，并用它在任何地方播种一个会话。 |
| **Subagent**         | 把任务送到它自己的上下文窗口，然后拿回一份报告。               |
| **`/compact`**       | 压缩这份上下文，并用摘要播种一个新会话。                       |

## 决策树

在边界处从上往下走。第一个**是**胜出。

**1. 你能在这个会话里继续吗？** 有两件事能让答案变成是：下一个阶段需要这个阶段作为**一手来源**，或者你还剩下足够的 [smart zone](https://www.aihero.dev/ai-coding-dictionary/smart-zone)（约 150k tokens）容得下下一个阶段。盘问 → 实现就是标准的"是"：实现想要那份推理一字不差的原样，而不是它的摘要。继续零成本、零损失，所以把它排在所有其他选项之前先排除掉。

**2. 这份上下文对接下来的事无关吗？** 这个会话里的一切（探索、决策、死胡同）都是可丢弃的吗？如果是，就 **`/clear`**。它是棋盘上最便宜的走法：不花时间，还能把整个窗口还给你。`/clear` 也并非不可逆：旧会话仍然可以恢复。

把这一步做错的代价是单向的。清空一份*相关*的上下文，你就丢掉了你所构建之物背后的**为什么**，而无论把差异读回多少遍都换不回来。

**3. 你需要交接吗？** `/handoff` 适用范围很窄。只有当你处在以下情形时才需要它：

- 切换到**新的 harness**（Claude → Codex），
- 搬到**新目录**或新仓库，
- 把工作交给一位**同事**，
- 或者在**阶段中途**分叉出一个支线任务，而不让你正在做的事脱轨。

这份清单就是全部条件。`/handoff` 买来的是**可携带性**：一个能旅行的文件。如果没有任何东西在旅行，你就不需要它。

**4. 这个任务能 AFK 完成吗？** 它的范围是否紧凑到你离开键盘、无需盯着也能跑？那就把它送给一个 **subagent**，让这个会话原封不动。自动审查是标准案例：agent 读取差异并报告，它做这件事时不需要你在场。

**5. 否则，用 `/compact`。** 上下文相关、同一个 harness、同一个目录，而且你需要留在环中：这就是决策树落下的地方，而且它经常落在这里。给它传一条指令（`/compact we're going to QA this area`），好让摘要保留下一个阶段需要的东西。

`/compact` 是**默认值，而非第一顺位的取用项**。它坐在底部，是因为它上面的四个问题要么更便宜、要么更精确。人们从它开始时的失败模式，是得到一个对某条被摘要压平了的决策自信地判断错误的新会话。

## 一手来源与二手来源

除了**继续**之外的每一步，都把一份**一手来源**变成一个**二手来源**：按原样发生的会话，被它的摘要取代。这笔交换的形态总是相同：

| 来源                           | 信息 | 噪音 | 腾挪空间 |
| ------------------------------ | ---- | ---- | -------- |
| 一手（继续）                   | 完整 | 很多 | 很少     |
| 二手（`/compact`、`/handoff`） | 有损 | 更少 | 很多     |

这就是为什么问题 1 排在最前。只有当留下来比省下来更贵时，你才付出这份有损的代价。

## 这些都是判断性的取舍

这些问题并不客观：每一个里面都有品味，同一个边界在两天里可能走出两个方向。价值在于**按顺序**问它们，并且是在边界处问，而不是在工作做到一半时问。
